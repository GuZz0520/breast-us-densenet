 1) 建环境（Python 3.13）
conda create -n BreastUS python=3.13 -y
conda activate BreastUS
python -m pip install --upgrade pip
python -m pip install -r requirements-no-torch.txt

安装 PyTorch（CPU 版；如有 NVIDIA CUDA，自行改成官网指令）
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu

2) 准备数据
从文件夹生成 CSV（假设 test 图片在 data\images\test\正常/良性/恶性 三个子文件夹）：
python scripts\make_csv_from_folders.py --root data\images\test --outdir data --test_only
# 会生成 data\test.csv，label 列来自子文件夹名

3) 运行评测（只评测测试集）
python -m src.engine.evaluate --cfg configs\baseline.yaml --weights outputs\best.pt --split test

[... ... ...]]
